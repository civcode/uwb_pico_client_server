## ☑ Phase 0 — Repository, build, and test wiring

| Acceptance criterion | Status | Evidence |
|---|---|---|
| Clean checkout configures and builds with one documented command | ☑ | `cmake --preset host-debug && cmake --build --preset host-debug` |
| `ctest` runs with at least one Catch2 test | ☑ | `uwb_unit_tests`, label `unit` |
| Host-only config requires no Pico SDK | ☑ | `host-debug` configures with `PICO_SDK_PATH` unset |
| Agreed top-level directories exist | ☑ | `shared/`, `server-core/`, `simulator/`, `client-core/`, `apps/`, `pico/`, `tests/` |
| Sanitizer preset builds and runs a trivial test | ☑ | `host-asan` preset |
| No UI library linked into protocol/server-core | ☑ | target link lists in `docs/dependency-policy.md` |
| No Pico SDK library linked into shared host targets | ☑ | `uwb_protocol`, `uwb_domain`, `uwb_server_core` link nothing platform-specific |
| CI runs host checks; HIL stays manual | ☑ | `.github/workflows/ci.yml`, `ci/run_local_ci.sh` |

## ☑ Phase 1 — Shared wire protocol v1.0

| Acceptance criterion (plan §12) | Status | Evidence |
|---|---|---|
| `uwb_protocol` has no Pico, socket, Asio, UART, UI, or filesystem dependency | ☑ | Standard-library includes only; `shared/protocol/CMakeLists.txt` links nothing; `pico-w` preset compiles the same library for RP2040 |
| All v1 generic payload types have encode/decode tests | ☑ | `payloads_test.cpp` (§15–§20), golden vectors in `tests/unit/gen/` |
| All v1 services have encode/decode tests | ☑ | `services_test.cpp` — 0x10, 0x11, 0x27, 0x22, 0x2E, 0x31, 0x3E, 0x40, 0x41 |
| All v1 event formats have encode/decode tests | ☑ | `events_test.cpp` — envelope (§32), measurement (§34), local position (§35), stream status (§36) |
| Fragmentation/coalescing parser tests pass | ☑ | `frame_parser_test.cpp` — byte-at-a-time, split-after-every-byte matrix, coalesced frames + trailing partial header |
| Oversized frames rejected before allocation/copy | ☑ | `FrameParser` validates the length field against `maxPayload` before buffering; test asserts no payload copy |
| Protocol and service errors are distinct types/enums | ☑ | `GenericHeaderNackCode`, `ApplicationNackCode`, `ServiceNrc`, `ProtocolErrorCode` (`errors.hpp`), documented in `docs/protocol_decisions.md` |
| UUID derivation has stable golden vectors | ☑ | `uuid_test.cpp` — board-id → UUIDv5 vectors, RFC 9562 Appendix A.4 vector |
| ASan/UBSan test run is clean | ☑ | `ctest --preset host-asan` (85/85), `ci/run_local_ci.sh all` |

Exit artifacts: `uwb_protocol` library, golden-vector suite (85 unit tests, regenerated by
`tests/golden/regenerate.sh` and verified by `tests/golden/verify.sh`), public protocol headers,
`docs/protocol_decisions.md`.
